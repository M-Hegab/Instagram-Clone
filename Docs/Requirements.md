# Instagram Clone — Requirements

A clone of Instagram where users register, log in, create posts with images, follow other users,
and see posts from the people they follow.

## MVP

- **R-01** User can register for an account, storing name, email/username, and password
- **R-02** User can log in with email/username + password
- **R-03** User can log out
- **R-04** User can search for other users by username
- **R-05** User can view any user's public profile: avatar, username, bio, follower/following
  counts, and their posts
- **R-06** User can go to settings and change password, change username, change bio, add or
  change their profile photo, and delete their account
- **R-07** User can create a post: one image plus an optional caption
- **R-08** User can choose SD or HD quality when uploading a post image
- **R-09** User can delete their own post
- **R-10** User can follow and unfollow other users
- **R-11** User can see who follows them and who they follow
- **R-12** User can see a feed of posts from the users they follow, newest first
- **R-13** User can manually refresh the feed to pull in newer posts
- **R-14** User can like and unlike a post (their own or another user's)

## Bonus (Not now)

- User gets an email verification when registering with email/password
- User can register/log in using Google
- Post images can have filters applied
- Post images can have text overlaid on them
- User can comment on posts
- User can see a global feed of all posts, not just followed users
- The feed auto-refreshes when a new post is added (WebSockets)
- User can send direct messages to other users
- User can create a story for followers
